# 08-ai-soc · AI 大 SoC

> **宗旨**：系统学习 AI 相关大 SoC——先打通芯片级通用骨架，再分别深入 TPU / GPU 两条加速路径。  
> 体例与 `01`–`06` 长文一致（扁平：一主题一篇 md）；需要总线 / 启动 / 核侧细节时**链回**既有成文，不在此目录重写第二套。

---

## 学习路径（本系列内）

```text
01-soc-common.md   SoC 通用：算力片骨架、NoC、内存层次、功耗/热、软件栈分界
        ↓
02-tpu.md          张量加速：脉动阵列、数据流、量化与片上缓冲、调度
        ↓
03-gpu.md          通用并行：SIMT、warp/波前、缓存与显存、与 CPU/NPU 协同
```

建议顺序：先 `01-soc-common` 建立「整片怎么拼」，再按兴趣进 `02-tpu` 或 `03-gpu`；两路可对照读（数据流 vs 可编程并行）。
