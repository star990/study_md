# 07-interview · 面试专题

> **宗旨**：总结面试题，温故而知新。  
> 与 `01`–`06` 的长文博客体例不同：这里以**真题驱动**，先收题、再补洞。

---

## 两大块（每篇 md 统一）

| 块 | 做什么 | 不做什么 |
|----|--------|----------|
| **一、真题记录** | 一条条记下真实遇到、且有价值的面试题：原题 / 追问 / 当时答法要点 / 参考答或自评 | 不编造「可能被问到」的题海；不写成刷题册目录 |
| **二、盲区延伸** | 由上述题目牵出的知识盲区，写清薄弱点与补强内容；可链回 `01`–`06` 成文 | 不另起无关百科；延伸必须能追溯到某一条真题 |

读法建议：先过真题（回忆现场），再进盲区（补短板）；同一题可在复盘后改写第二块。
